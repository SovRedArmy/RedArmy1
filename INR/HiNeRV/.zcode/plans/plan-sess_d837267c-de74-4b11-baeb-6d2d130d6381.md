# C1 实验：UAR-NVC 式「失真-码率-量化」全程联合训练（单点验证）

## 机制结论（已完成的研究）

**UAR-NVC 的联合优化实现**（本地代码已核实）：
- 每层权重经 `register_parametrization(v, 'weight', QuantEntropy())` 注册参数化（`UAR-NVC/compression/quant_utils.py:161-164`），每层一个可学习标量 `q_step`（初始 1e-3）；
- **`start_quantization` 在主训练开始前调用**（`util/train_model.py:191`）→ 从 epoch 0 起每个 batch 的前向都用 `_ste(W/q_step)·q_step`（STE 直通）的量化权重，量化鲁棒性不是事后补的，而是权重从头在量化约束下生长；
- 每 batch 计算 `loss = bpp + λ·D`（`util/metrics.py:198`）：bpp = 量化后整数按零均值高斯（scale=std，可学习）估计的 Σ−log₂p / 总像素；D = 0.7·L1+0.3·MS-SSIM；λ=5·modelsize/gop；
- 训练结束直接用学到的 q_step+scale 做 rANS 熵编码（`codec_utils.py:243-245`），训练率估计与最终码流同源。
- **完整形态在本地 `INR/NVRC/`（NeurIPS 2024）**：三层熵模型（网格用掩码 3D 卷积自回归预测逐元素 μ/σ、层权重用双轴分解）、soft-round-noise→quant-noise 退火、每 8 个失真步 1 个率步（梯度×8）。
- **MyHiNeRV 已有 QEC/hyper 移植但只在最后 12ep QAT 激活**——主训练 420ep 全程无率信号，这正是 B0 压缩损失 0.85dB、探针随训练恶化的结构性原因。C1 把激活点提前到 epoch 0。

## C1 配置（用户已确认：单点验证、不剪枝）

在 **B1（采样加权赢家）** 配置上叠加：`--quant-mode qec --w-rate 1.5 --joint-rate true`，420ep，无剪枝（PREP=0，保留 12ep 低 lr 终段作硬量化精调，对应 NVRC 的 S2），保留每 60ep 探针（改为 QEC 直压版）。采样加权配置与 B1 逐参数一致（正交叠加）。

## 实施步骤

### 1. 代码改动（MyHiNeRV，约半天）
- **hinerv_main.py**：新参数 `--joint-rate`（bool）、`--rate-warmup-epochs`（默认 15）。
- **train_lib.py `train_model`**：`joint_rate=True` 时在主训练循环前调用 `start_quantization(model)`（量化前向从 epoch 0 生效；q_step 已在模型构建时注册、已在 optimizer 中）；`enable_pruning=False` 时跳过剪枝阶段（机制已存在，GOP 模型在用）。
- **train_lib.py `compression_probe`**：joint/qec 模式下探针改为「直接用当前 q_step 压缩→解码→评估」（跳过即时剪枝与 100-batch QAT——权重本来就是量化训练出来的），得到真实 RD 点轨迹；顺手修复探针 yaml 被重启覆盖的问题（写入前与已有文件合并）。
- **hinerv_tasks.py**：rate 损失乘 ramp 因子 `min(1, epoch/rate_warmup_epochs)`（前 15ep 从 0 线性升到 1，防止早期率梯度干扰收敛；复用现有 aux 调度模式）。
- **run_ablation.sh**：新增 `C1)` 分支 = B1 全部 dyn 参数 + qec/joint-rate/w-rate 1.5 + `--workers 2`（OMP_THREADS=8）+ PREP=0 QE=12 EP=420，exp-name `C1-joint-qec-420`；supervisor QUEUE 追加 C1。

### 2. 冒烟测试（GPU5，约 30 分钟）
3-epoch 短程：验证量化前向激活、rate 项出现在 loss 分解、q_step 开始更新、QEC 探针能出码流+解码评估、无参数化冲突。

### 3. 上线与监控
- 重启监督器（MAX_JOBS 5→7，state 文件延续），C1 立即上 GPU5（当前空闲），不影响 B2/B4/A1/r 系列。
- 观察节点：ep15（ramp 结束后 loss 分解中 rate≈多少 bpp）、ep60（首个 QEC 探针 RD 点，直接与 B 系列 Q8 点 30.48-30.55 对比）。

### 4. 判定标准（单点验证成功与否）
- 训练稳定不崩（rate 项收敛、q_step 稳定在合理区间 ~0.02-0.03）；
- ep60 探针 RD 点与 B 系列可比：**C1 在 bpp≤0.0176 时压缩后 PSNR ≥ 30.5（B1 Q8 水平）即机制有效**；最终以 420ep 完整点 vs B1/B1r 曲线算 BD-RATE；
- 浮点 PSNR 低于 B1 属预期（权重为可压缩性塑形），不作为失败信号。

### 5. 后续（验证成功后，另行确认）
扩 RD 点（λ∈{0.75, 3.0} 或位宽锚定），并入终版报告与 B 系列/r 系列统一 BD-RATE 对比。

## 风险与对策
- STE 硬量化从 ep0 可能拖慢早期收敛 → rate-warmup ramp + UAR-NVC 本身无退火也work 的先例；
- 一个 λ 只出一个 RD 点（A2 已见）→ 本就是单点验证，扩点方案已列；
- 与 B 系列对比时注明 C1 无剪枝（NVRC 同款设计，码率控制交给 q_step+熵模型）。
